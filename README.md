# GSEA operator

GSEA for UKA results, using fold change (e.g. Median Kinase Statistic).
It returns KEGG pathways.

##### Usage

Input projection|.
---|---
`y-axis` | UKA Fold Change (Median Kinase Statistic or Median Kinase Change).
`rows` | Kinase Names
`color`| Kinase Family
`columns`| Group-group comparisons (`contrast` or Supergroup_contrast)
